Stockfish 19 (Lite NNUE, single-threaded WebAssembly build)

ZIGRAX uses this engine for game analysis, deep analysis, the position explainer
and the admin anti-cheat checks. The ZIGRAX engine still plays the bot levels,
puzzles and endgames.
